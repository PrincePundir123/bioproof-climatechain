# BioProof implementation checklist

Stack: Next.js App Router, strict TypeScript, Supabase Auth/Postgres/private Storage, Zod, ethers/Sepolia. Vercel deployment target. No secondary database.

1. Runnable foundation and landing page.
2. Domain rules, canonical event chain, conflicts, SoilSafe, tests.
3. Transactional Supabase schema, authorization and custody APIs.
4. Isolated synthetic demo and investigation workspace.
5. Private uploads, optional AI extraction, public verification and proof replay.
6. Registry contract, anchoring integration and deployment instructions.
7. Browser checks, production build, documentation and submission materials.

Each milestone receives a meaningful Git commit. Existing initial commit is preserved. External services are never represented as configured until verified.
